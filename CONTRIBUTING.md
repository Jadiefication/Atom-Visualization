# Contributing to Haje

First off, thank you for considering contributing to Haje! It's people like you that make Haje such a great tool.

## How Can I Contribute?

### Reporting Bugs

- Use a clear and descriptive title for the issue.
- Describe the exact steps which reproduce the problem in as many details as possible.
- Explain which behavior you expected to see instead and why.

### Suggesting Enhancements

- Use a clear and descriptive title for the issue to identify the suggestion.
- Provide a step-by-step description of the suggested enhancement in as many details as possible.
- Explain why this enhancement would be useful to most Haje users.

### Pull Requests

- Ensure the test suite passes (`cargo test`).
- Update the documentation if you're introducing new features or changing existing ones.
- Follow the existing code style.

## Styleguides

### Rust Styleguide

- All code must be formatted with `rustfmt`.
- Follow the recommendations of `clippy`.
