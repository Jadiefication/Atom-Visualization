# Security Policy

## Supported Versions

The following versions of Haje are currently being supported with security updates:

| Version | Supported |
| ------- |-----------|
| 0.2.x   | ✅         |
| < 0.2.0 | ❌         |

## Reporting a Vulnerability

If you discover a security vulnerability within Haje, please send an e-mail to Jadie via [jadeczjade008@gmail.com](mailto:jadeczjade008@gmail.com). All security vulnerabilities will be promptly addressed.
